
# PlaceMate AI – Intelligent Placement Preparation and Career Assistant

## Project Overview

PlaceMate AI is an integrated placement preparation
platform designed to help students prepare effectively
for campus recruitment.

The application combines resume analysis, job matching,
skill gap identification, personalized learning roadmaps,
mock assessments, interview preparation and progress
tracking into a single interactive platform.

## Key Features

### 1. Resume Analysis
- PDF resume upload and text extraction
- Resume content scoring
- Technical skill identification
- Section-wise improvement recommendations

### 2. Job Matching and Skill Gap Analysis
- Resume and job requirement comparison
- Job matching score
- Identification of matching and missing skills
- Company-specific preparation recommendations

### 3. Personalized Learning Roadmap
- Customized placement preparation plans
- Skill-based learning recommendations
- Day-wise preparation schedules

### 4. Mock Assessment
- Question bank containing 514 questions
- Multiple assessment categories
- Difficulty-based assessments
- Performance evaluation and feedback

### 5. Interview Preparation
- Technical interview questions
- HR interview questions
- Interview practice and preparation guidance

### 6. Progress Tracker
- Assessment performance tracking
- Placement preparation progress monitoring
- Interactive performance dashboard

## Installation and Execution

1. Clone or download the repository.

2. Install the required dependencies:

       pip install -r requirements.txt

3. Run the Streamlit application:

       streamlit run app.py

## Project Objective

To provide students with a centralized platform for
identifying skill gaps, improving resumes, practicing
assessments and preparing confidently for placements.
